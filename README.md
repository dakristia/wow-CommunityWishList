# CommunityWishList

A World of Warcraft addon for WoW: Forever. It keeps a shared wish list for your guild and your friend groups. Members claim a wish ("I will send you 40 x Peacebloom"), mail the items, and the wisher gets an alert.

- `CommunityWishList/` is the addon. Read `CommunityWishList/docs/design.md` first.
- `tests/CommunityWishList_Tests/` holds the headless tests. They run through [wow-addon-workshop](https://github.com/dakristia/wow-addon-workshop) with `bin/test`.
